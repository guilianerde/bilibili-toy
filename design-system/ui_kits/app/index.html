组件构成 · composition map

  • <App>应用外壳：品牌栏、玩具切换、舞台
  • <MarketBoard>行情台：状态条 + 事件快报 + 四栏（市场 / 交易 / 持仓 / 资讯）；9 节剧情按时钟自动推进，收盘切换为结算单
  • <MarketTabs>栏目标签：键盘左右切换、资讯未读点、面板显隐与可访问选中态
  • <EventTape>事件快报条：当前事件、下一节与倒计时，点击进入资讯栏
  • <RoundStrip>顶部状态条：回合、纪年、下一事件、倒计时、总资产、收益率
  • <StoryBeat>剧情节拍卡：阶段、进度、势力影响与实盘倒计时
  • <PriceBoard>势力行情 + 逐秒抖动分时 + 逐节收盘 K 线
  • <TickerBoard>11 家势力按钮、印章徽记、逐秒抖动分时折线与价格刻度
  • <Composer>交易单：买卖切换、费用估算与提交
  • <InputBar>股数输入与「最大」快捷动作
  • <HoldingsCard>资产读数与持仓表格：持仓、现价、浮盈
  • <TradeReceipt>成交回执：最近成交在前，含成交价与手续费
  • <ClosingSummary>收盘结算：期末资产、收益率、最高资产、成交与手续费
  • <DubBoard>音效键板、时间轴轨、录制与回放
